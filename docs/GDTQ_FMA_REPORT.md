# gdtq 0.0.3 融合積和と初等関数の評価レポート (GPU)

dtq 0.0.3 の評価レポート (`dtq-0.0.3/docs/dtq_fma_report.tex`) の GPU 版。
CPU 版 dtq 0.0.3 で行った分岐なし多倍長融合積和 (FMA) の導入と、
その初等関数・多項式評価への波及を、CUDA 実装 gdtq 0.0.3 について
同じ観点で測定した結果をまとめる。

## 1. 実験環境と測定方法

| 項目 | 内容 |
|---|---|
| GPU | NVIDIA GB10 (sm_121)、ドライバ 580.159.03 |
| CUDA | 13.0 (V13.0.88)、`-O3 -fmad=false` |
| 精度クラス | gdd/gtd/gqd (double 2/3/4 語)、gds/gts/gqs (float 2/3/4 語) |
| FMA 精度検証 | test/fmatest: ホスト側の正確な展開演算 (Shewchuk) を参照値に 20000 サンプル |
| 初等関数精度 | test/elembench: MPFR (作業精度 2p+64 ビット) を参照値に 200 サンプル |
| 時間測定 | test/fmabench: 依存演算 32 個の連鎖 ×2^20 要素、5 回中最良。 test/elembench: 2^20 要素のカーネル時間 / 要素数、5 回中最良 |

エラーの単位はいずれも対象クラスの eps (= 2^-104 / 2^-156 / 2^-209 /
2^-46 / 2^-69 / 2^-93) あるいは ulp (相対誤差 × 2^総ビット数)。

## 2. FMA カーネル単体の性能 (fmabench)

0.0.2 の乗算+加算経路との比較 (倍率、1 超が高速化):

| クラス | a*b+c | a/b | sqrt(a) |
|---|---|---|---|
| gdd_real | 1.20x | 0.47x | 1.61x |
| gtd_real | 1.35x | 1.40x | 1.58x |
| gqd_real | 1.19x | 0.81x | 1.93x |
| gds_real | 1.16x | 0.95x | 7.44x |
| gts_real | 1.33x | 2.40x | 1.88x |
| gqs_real | 1.20x | 1.39x | 2.18x |

a/b が 1 倍を切る 3 クラスは意図的な精度優先の結果である。0.0.3 は
dtq 0.0.3 に合わせ、除算の残差をすべて div/sqrt-safe な融合積和
(`dw_fma_safe`、gdd は 3 商・gqd は 5 商) で構成する。以前の gdd/gds
専用のスカラー残差ショートカットは高速だが、残差入力が非重複展開で
あることを仮定できず、機械証明された誤差保証の対象外だった。

## 3. FMA の精度 (fmatest、20000 サンプル、単位: eps)

|  | fma(a,b,c) | 完全相殺 c=-(a*b) | a/b | sqrt(a) |
|---|---|---|---|---|
| gdd_real | 0.627 | 0.377 | 0.360 | 3.511 |
| gtd_real | 0.290 | 0.162 | 0.175 | 0.596 |
| gqd_real | 0.195 | 0.092 | 0.126 | 0.748 |
| gds_real | 0.250 | 0.000 | 0.126 | 2.958 |
| gts_real | 0.121 | 0.005 | 0.091 | 0.598 |
| gqs_real | 0.057 | 0.003 | 0.083 | 0.390 |

完全相殺 (c = -(a*b)、先頭語がほぼ全て打ち消し合う) でも全クラス
0.5 eps 未満に収まる。これは機械証明済みの定式化が通常の誤差保証
|error| <= few * eps * (|a*b| + |c|) を相殺時にも保つことの実測で、
polyeval が根の近傍でも素の fma で走れる根拠である (CPU 版 dtq
0.0.3 と同じ結論)。

## 4. 初等関数への波及 (0.0.2 相当 → 0.0.3)

変更点は dtq 0.0.3 と同一:

1. exp / expm1 / sin / cos / sincos の Taylor カーネルを 1 項 1 融合
   積和 (s = fma(p, 1/k!, s)) に。収束判定は先頭語の積で行い、項を
   実体化しない。
2. gtd/gqd の exp を二段テーブル駆動還元
   (a = m log2 + j1/64 + j2/8192 + r, |r| <= 2^-14) に書き換え、
   16 回の自乗はしごを除去。テーブルは定数メモリに常駐
   (GQDStart がアップロード、GTDStart は QD 表を切り詰めて生成)。
3. log の Newton 反復の初期値を一段下のクラスの log (gtd/gqd は gdd、
   gts/gqs は gds) から取り、反復を 1 回に削減。
4. `expm1`(全 6 クラス)、`log10`(全 6 クラス)、`polyeval`(Horner
   法 1 ステップ 1 融合積和、全 6 クラス) を追加。
5. log(0) = -inf、log(負) = nan、exp のオーバーフロー = +inf という
   MPFR/IEEE セマンティクスに統一 (elembench の特殊値テストで全クラス
   PASS)。

カーネル時間 (benchmark、10^6 要素、秒):

| 関数 | 旧 | 新 | 倍率 |
|---|---|---|---|
| gqd exp | 0.050 | 0.029 | x1.7 |
| gqd log | 0.157 | 0.034 | x4.6 |
| gtd exp | 0.020 | 0.009 | x2.2 |
| gtd log | 0.042 | 0.014 | x3.0 |
| gdd exp/log | 0.003 / 0.004 | 0.003 / 0.004 | 変化なし |

gdd は元々 512 還元 + 9 回自乗で軽く、FMA 化の利得はカーネル時間の
測定粒度未満。float 系の log も初期値改善で gts x2 / gqs x3 程度
短縮している。

## 5. 初等関数と polyeval の精度 (elembench、MPFR 参照、単位: ulp)

max_err[ulp] (N=200、代表値):

| 関数 | gdd | gtd | gqd | gds | gts | gqs |
|---|---|---|---|---|---|---|
| sqrt | 5.4 | 1.5 | 1.6 | 3.9 | 1.9 | 1.4 |
| exp | 7.5 | 6.5 | 2.3 | 14 | 1.3 | 3.8e5 |
| expm1 | 12.5 | 6.1 | 2.8 | 4.0 | 1.5 | 4.5e4 |
| log | 11 | 17 | 72 | 6.9 | 12 | 3.6e4 |
| log10 | 12 | 19 | 59 | 4.2 | 3.0 | 3.6e4 |
| sin | 36 | 33 | 4.0 | 711 | 7.8e5 | 1.3e13 |
| cos | 50 | 22 | 77 | 72 | 7.8e5 | 1.3e13 |
| poly15 | 0.96 | 0.31 | 0.23 | 0.85 | 0.49 | 0.19 |

- polyeval は全クラスで 1 ulp 未満 (誤差は項和スケール基準。融合積和の
  保証がそのまま現れる)。
- 倍精度系の数十 ulp は log(x)≈0 や sin(x)≈0 近傍での相対誤差の増幅で、
  CPU 版 dtq の結果 (dd sin 144 ulp / cos 284 ulp など) と同種のもの。

## 6. 融合化と無関係の既存の弱点 (float 系)

CPU 版 dtq の float 系クラスは倍精度実装への委譲で計算するため
きれいな値を示すが、GPU 版はネイティブ float 実装であり、次の
表現・定数精度の限界が測定に現れる (いずれも 0.0.2 から存在し、
今回の変更で悪化していないことを旧版との比較で確認済み):

- gts/gqs の sin/cos: 引数還元定数 (2π等) が float 語の展開であるため
  約 52 ビットで頭打ち (min_bits 52.4)。
- gqs の exp/log: 2^16 自乗はしご + float 有効レンジの床により
  約 78〜81 ビット (理論値 96 ビット)。
- float 系の有効レンジ: 最下位リムが float 正規化数範囲を割ると
  1/2 倍ごとに約 1 ビットずつ精度低下
  (|x| < 2^-102 / 2^-78 / 2^-54、README 参照)。

## 7. まとめ

- dtq 0.0.3 の FMA・初等関数・polyeval の設計は GPU でもそのまま成立
  する。完全相殺時の誤差保証も実測で確認した。
- テーブル駆動 exp と log の初期値改善により、gqd log x4.6 など
  倍精度系初等関数が大きく高速化した。
- 除算は安全な残差構成を優先して一部クラスで 0.0.2 経路より遅い。
  速度を優先する場合は `-DGQD_NO_FMA_DIV` で旧経路に戻せる。
- float 系の sin/cos・gqs exp/log の精度床はネイティブ float 実装固有
  の既存の限界であり、融合積和化とは無関係。

再現方法:

    cd test
    make
    ./fmatest            # FMA / 除算 / 平方根の精度
    ./fmabench           # 0.0.2 経路との速度比較
    ./elembench [N]      # 初等関数の精度 (MPFR 参照) と時間
    ./benchmark          # CPU QD との突き合わせ
